## Purpose
Learn to use pytest, write assertions, test calculator functions, fix failing tests, and check exceptions.

## Files
- `calculator.py`: Addition, subtraction, multiplication, and division functions.
- `test_first.py`: Basic tests for numbers, strings, and lists.
- `test_output.py`: Test with print output.
- `test_calculator.py`: Calculator tests and the Arrange, Act, Assert pattern.
- `test_failing.py`: A test that was intentionally failed and then corrected.
- `test_exceptions.py`: Tests for division by zero.

## Run Tests
In Windows Git Bash:

```bash
cd ~/testing-lab
source venv/Scripts/activate
python -m pytest -v
```
